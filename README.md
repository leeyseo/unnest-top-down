# Unnest

AI workflow를 시각적으로 설계하고 실행하는 플랫폼

Unnest는 AI workflow를 구성하고, 테스트하고, API 또는 MCP Server로 실행할 수 있는 시각적 개발 환경입니다.

## 주요 기능

- Drag-and-drop 기반 Flow 설계
- 주요 LLM, Vector Database 및 AI 도구 연동
- Playground를 통한 즉시 실행 및 검증
- API 및 MCP Server 실행
- Flow JSON 가져오기와 내보내기
- Custom Component 작성

## 로컬 개발

Python 3.10–3.14와 [uv](https://docs.astral.sh/uv/)가 필요합니다.

```shell
make run_cli
```

기본 접속 주소는 `http://127.0.0.1:7860`입니다.

상세한 개발 환경 구성은 [DEVELOPMENT.md](./DEVELOPMENT.md)를 참고하세요.
